# Memos

Lightweight, privacy-first note-taking: quick markdown memos with tags, search and a clean timeline.

## What Harbor does

- Runs Memos on 127.0.0.1 with its data in a retained volume.

## Storage

- `data`: Notes, attachments and settings.
- Managed volumes and your folders are retained on remove; Harbor never deletes them.

## First run

1. Open the app and create the first account.

## Notes

- Memos renders a generated monogram in Harbor (no bundled logo).
