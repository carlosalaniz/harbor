# Actual Budget

Local-first personal finance: envelope budgeting with bank import, fast and private, synced through your own server.

## What Harbor does

- Runs the Actual sync server on 127.0.0.1 with its data in a retained volume.

## Storage

- `data`: Budget files and server data.
- Managed volumes and your folders are retained on remove; Harbor never deletes them.

## First run

1. Open the app and set the server password.
2. Create a budget or import from YNAB or another Actual file.
