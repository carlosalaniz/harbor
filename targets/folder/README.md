# Another disk

Backs your apps up to a folder on a second disk or a USB drive mounted on this machine (`/mnt/…` or
`/media/…`; Settings → Storage mounts one). Fast and free, but it sits in the same house as the original:
pair it with a place far away. Harbor creates the folder at the first test. Everything in it is encrypted;
unplugging the drive only makes that place fail its next run until it is back.
