## Harbor 0.17.0 — first beta

**Who this is for.** One administrator, one Ubuntu 24.04 x86‑64 machine you are willing to
reinstall, and a wish to run your own apps privately. Not for data you have no other copy of.

**Install.** `curl -fsSL https://raw.githubusercontent.com/carlosalaniz/harbor/main/install.sh | sudo bash`
then open `http://harbor.local/` (or the machine's IP) and finish the wizard with the printed
setup code. The installer takes the newest release, which is this one.

**Do not use anything older than 0.17.0.** Releases before it said "installed encrypted" and were
not: app data on disk was plaintext. 0.17.0 seals every app home with the kernel's own encryption
(fscrypt v2, one key per app) and proves it with a Docker-bypass test in `docs/VERIFICATION.md`.
If you tried an earlier build, uninstall it (`sudo /opt/harbor/bin/harbor uninstall --yes`) and
install fresh; the old app homes were never sealed.

### What to expect

- App Store with 17 packages pinned by image digest; install, update with rollback, remove, purge.
- A launcher home screen, publishing to your tailnet (Tailscale) or a public HTTPS address (Caddy
  + Let's Encrypt), LAN mode at `http://harbor.local`.
- Removable drives: mount, eject, format as ext4 from Settings, bring‑your‑own folders with a
  drive guard.
- **Encrypted app homes.** Install an app "Local" or on an external drive; its whole data,
  database included, is sealed on disk. Locked means unreadable, for root and Docker too.
- **One Harbor recovery key**, twelve words shown once at setup, opens every app this Harbor
  encrypts on any machine. Write it on paper. An app you give its own passphrase also gets its
  own twelve words.
- A passphrase is optional everywhere. If you use your Harbor password as an app's passphrase,
  logging in unlocks that app too. Any other passphrase is asked for after a lock or reboot.
- Lock an app (when stopped) to evict its key; a reboot locks everything until the first login.

### What not to trust yet

- **Headless boxes.** After a power cut or reboot, sealed apps stay locked, and therefore down,
  until someone logs in to the console. Automatic unlock (keyfile/TPM) is a 1.0 item.
- **App‑generated secrets** (database passwords, provisioned admin logins) live in plaintext under
  Harbor's state directory, mode 0600. See `SECURITY.md`.
- **`harbor.local` on some networks.** This release stops avahi from publishing Docker bridge
  addresses under the name (the cause of "it stopped resolving" on a Mac). If it still fails,
  use the machine's IP and see the operator guide §7.
- **Not yet run on this exact build:** a fresh‑machine acceptance pass and cross‑host mDNS from a
  second device. Both are scheduled; the evidence log says what was and was not run.
- No backups of application data, no multi‑user, no LAN HTTPS, no ARM builds.
- The repository has no LICENSE yet: all rights reserved until 1.0.0.

**Report a problem:** run `harbor diagnostics` on the machine and paste the block into
https://github.com/carlosalaniz/harbor/issues/new?template=bug.md. It contains versions, host
facts, app states and a log tail, never secrets.
