## Harbor 0.20.0 — packages may set `command:`

Everything in the [0.19.1 beta notes](https://github.com/carlosalaniz/harbor/blob/main/docs/releases/v0.19.1.md)
still applies. New in this release:

- **Packages may set `command:` per service** (decision 123): an argument array, written exactly as
  the container receives it (`$` is literal; Harbor escapes it for Compose). One image can now run
  as web server, scheduler and workers, and databases can take server flags — common in upstream
  Compose files. `entrypoint:`, `privileged`, `cap_add`, `devices`, host networking and bind mounts
  stay forbidden. Details: `docs/DEVELOPER_PACKAGES.md` §3.

Already running Harbor? Settings → Overview → Update.
