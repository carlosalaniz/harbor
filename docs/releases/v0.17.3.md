## Harbor 0.17.3 — Home calls you by name, plus two console fixes

**Who this is for.** Anyone who sees `Good evening, Admin` and wants their name there instead.
Upgrade from the console (Overview → Update) or reinstall with the one-liner; nothing about existing apps changes.

**Install.** `curl -fsSL https://raw.githubusercontent.com/carlosalaniz/harbor/main/install.sh | sudo bash`
then open `http://harbor.local/` (or the machine's IP) and finish the wizard with the printed
setup code. The installer takes the newest release, which is this one.

### What to expect

- **Home greets you by name.** The setup wizard asks `What should Home call you?` (optional),
  and Settings → Account has the same card later (Set / Change / Clear). The login name stays
  the credential — this is only the greeting, so `Good evening, Admin` becomes `Good evening, Carlos`.
  Clearing it falls back to the login name. CLI: `harbor account name [name]`.
- **Dialogs open again.** The Network trust sheet (`How to trust it on a new device…`) looked dead
  because the shared dialog wrapper closed itself during React's dev remount cycle. It no longer does.
- **Wide screens are centered.** The console column centers instead of pinning left, with wider caps
  on big monitors (1440px at ≥1600px, 1600px at ≥2000px).

### What not to trust yet

- Same list as 0.17.0/0.17.1/0.17.2 (headless boxes stay locked until login, app-generated secrets are
  plaintext under the state dir, no backups, no multi-user, no ARM builds).
- The repository has no LICENSE yet: all rights reserved until 1.0.0.

**Report a problem:** run `harbor diagnostics` on the machine and paste the block into
https://github.com/carlosalaniz/harbor/issues/new?template=bug.md. It contains versions, host
facts, app states and a log tail, never secrets.
