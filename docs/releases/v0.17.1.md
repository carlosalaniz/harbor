## Harbor 0.17.1 — secure addresses on the home network

**Who this is for.** Anyone running Harbor in LAN mode who wants `https://harbor.local`
with no warning. Upgrade from the console (Overview → Update) or reinstall with the
one-liner; nothing about existing apps changes.

**Install.** `curl -fsSL https://raw.githubusercontent.com/carlosalaniz/harbor/main/install.sh | sudo bash`
then open `http://harbor.local/` (or the machine's IP) and finish the wizard with the printed
setup code. The installer takes the newest release, which is this one.

### What to expect

- **Secure addresses** (Settings → Network, needs LAN mode): Harbor mints its own
  certificate on the machine — nothing leaves your network, nothing phones home — and
  serves the console at `https://harbor.local/` plus one secure address per app.
- **One trust per device.** The card shows whether *this* browser already trusts the
  certificate; *How to trust it on a new device…* walks through macOS, iOS (two stages:
  install the profile, then enable full trust), Windows, Android and Linux, plus the
  Firefox note (it keeps its own store on every platform). Compare the fingerprint
  shown on the card with the one on the device before trusting.
- **First-visit helper.** Until a device trusts the certificate, the plain-HTTP console
  shows a banner pointing at the trust sheet. (The browser's own warning page for the
  HTTPS address cannot be styled by Harbor.)
- Off by default; plain HTTP stays as it is. CLI: `harbor network https` /
  `harbor network https on|off` / `harbor network ca`.

### What not to trust yet

- Same list as 0.17.0 (headless boxes stay locked until login, app-generated secrets
  are plaintext under the state dir, no backups, no multi-user, no ARM builds).
- The secure app ports are hostPort + 20000 (deterministic, no configuration); an app
  whose HTTP port sits above 45535 gets no secure address rather than a wrong one.
- The repository has no LICENSE yet: all rights reserved until 1.0.0.

**Report a problem:** run `harbor diagnostics` on the machine and paste the block into
https://github.com/carlosalaniz/harbor/issues/new?template=bug.md. It contains versions, host
facts, app states and a log tail, never secrets.
