## Harbor 0.22.0 — one app, several domains

Everything in the [0.21.0 notes](https://github.com/carlosalaniz/harbor/blob/main/docs/releases/v0.21.0.md)
still applies. New in this release:

- **Publish an app under more than one domain** (decision 127), e.g. an ERP at `erp.example.com` and
  `customers.example.org`. Each domain gets its own certificate and its own protection. Console:
  *Publish…* → **Add another domain**; each domain has its own Withdraw and Make primary. CLI:
  `harbor expose <app> --via public --host <fqdn>` again with another hostname.
- **Pick the main domain**: `harbor primary <app> public --host <fqdn>` (default: the first one
  published). Apps that embed their address use the main one; hooks such as Nextcloud's trusted
  domains get all of them.
- **Withdraw one domain**: `harbor unexpose <app> --via public --host <fqdn>`. With several domains
  Harbor asks which one instead of guessing; withdrawing the main one makes the next one main.
- State schema v10; the upgrade migrates in place and keeps every published address.

Already running Harbor? Settings → Overview → Update.
