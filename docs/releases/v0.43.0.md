# Harbor 0.43.0

**A generated password can stay viewable on the app page.**

- **Saved passwords:** an app's Settings tab can list a password Harbor generated for it. **Show…** displays it after you type your Harbor password. Packages choose which values; every other generated value is still shown only once.

**Package format:** new optional `secrets[].revealable: true` (needs `showOnce`). First accepted by 0.43.0, so an app that uses it declares `release.minHarbor: "0.43.0"`.

**API:** new `POST /v1/instances/{id}/secrets/reveal`; instance summaries gain `revealableSecrets`.
