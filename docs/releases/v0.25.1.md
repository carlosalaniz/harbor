## Harbor 0.25.1 — big USB drives show up

Everything in the [0.25.0 notes](https://github.com/carlosalaniz/harbor/blob/main/docs/releases/v0.25.0.md)
still applies. Fixed in this release:

- **External USB hard drives that did not appear in Settings → Storage now do.** Many large USB disks
  (for example a 14 TB Seagate Expansion) do not say they are removable, so Harbor ignored them. Harbor
  now treats any drive on USB as external, except the disk the system itself runs from.

Already running Harbor? Settings → Overview → Update.
