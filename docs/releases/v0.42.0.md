# Harbor 0.42.0

**Simpler app and install pages, one password per app, Tailscale by default.**

- **App page:** four tabs (Overview, Access, Settings, Data) instead of one long page. Every page of an app now lists its addresses.
- **Install page:** four answers: where it lives, who can reach it, password, internet.
- **One password per app:** Harbor's login now uses one password for all of an app's pages. An app that had one per page keeps its main page's password; the others stop working at its next restart. On Android Link, anyone with the password can now also pair phones.
- **Add a domain:** one dialog with the DNS record to create and a live check, no separate registration step. New domains use the app's password instead of basic auth; existing ones keep working.
- **Tailscale by default:** a new Harbor puts every app on Tailscale once it is connected. An existing Harbor asks once on the Publishing page.
- **Tailscale addresses now use the cookie firewall,** so one app cannot read another's login cookies. Harbor moves existing addresses by itself.

**API changes:** `login` on a configure plan is now `{on?, password?}`, the `login` DTO is one object, `/login/reveal` answers `{password}`, and the submitted secret is `harbor.login`. The package format does not change; no `release.minHarbor` is needed.
