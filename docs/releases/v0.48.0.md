# Harbor 0.48.0

**Decide who reaches the apps you publish on the internet.**

- **Settings → Allowed addresses** (new): switch from *Everyone* to *Allowed list only*, and every connection from an
  address that is not on your list is dropped before it opens. No page, no login screen, no answer. Your home
  network, the tailnet and this machine always get in, so a wrong list never locks you out.
- Add one address or a range, with a label, tags and an optional expiry (24 hours, 7 days, 30 days).
- **Dropped** lists every address that was turned away, how many packets it sent and when, with **Look up** (country
  and network from a database on your machine; the address never leaves it), **Tag** and **Allow…**. A notification
  tells you when one address keeps trying, and a day before an entry expires.
- From a terminal: `harbor access`, `harbor access mode list|everyone`, `harbor access add <address>`,
  `harbor access attempts`, `harbor access lookup <address>`.
- It covers port 443, where every public app is served. Port 80 stays open so Let's Encrypt can renew certificates.

**Apps that only go online through your VPN.** An app can now say it must only reach the internet through the VPN in
Settings → VPN. Direct is never offered for it, and it installs once a VPN is set up. The first one is **IP Lookup**
(App Store), which adds **Ask online** to Allowed addresses: abuse reports and hosting/VPN/Tor flags from AbuseIPDB
and ipinfo. Those services see your VPN's address, not your home's; they do see the address you ask about.

**Package format** (first accepted by 0.48.0, so an app that uses them declares `release.minHarbor: "0.48.0"`):
`network.requireVpn: true`, and `provides.ipLookup: { endpoint, path }` for an app that answers Harbor's address
lookups. See docs/DEVELOPER_PACKAGES.md.

**Good to know**

- Counts are packets, not tries: a client resends its first packet when nobody answers, so one try counts about 2–3.
- Location data is DB-IP Lite (downloaded from db-ip.com the first time you look an address up, refreshed monthly).
- Not yet tried on a real public server with Caddy: the firewall rules were proven in an Ubuntu 24.04 container.
